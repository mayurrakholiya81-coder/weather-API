## Project Overview

This project is a weather-focused web application designed to present weather information in a clean, responsive, and user-friendly interface. The application uses frontend web technologies and, where configured in the source, weather/location APIs to retrieve and display relevant weather data.

## Technologies Used

- Fetch API
- Weather API
- HTML5
- CSS3
- JavaScript

## Main Features

- Current-location / geolocation support
- Weather forecast information
- Weather metrics such as temperature, humidity, wind, or pressure
- Location/weather search functionality
